# hotel-booking-systemFeatures
Guest Features
🛏️ Room browsing with filters (type, price, amenities)

📅 Availability calendar and real-time booking

🔐 Secure user authentication (JWT)

📱 Responsive design for all devices

💳 Integrated payment processing (Stripe/PayPal)

📧 Booking confirmations via email

Admin Features
📊 Dashboard with key metrics

🏨 Room management (CRUD operations)

👥 User management and permissions

💰 Payment processing and refunds

📈 Reporting and analytics

Tech Stack
Frontend
React.js with hooks

Redux for state management

Axios for HTTP requests

Tailwind CSS for styling

Date-fns for date handling

Backend
Node.js with Express

MongoDB with Mongoose

JWT authentication

Redis for caching (optional)

Nodemailer for email services

DevOps
Docker containerization

CI/CD with GitHub Actions

AWS/Heroku deployment ready

Getting Started
Prerequisites
Node.js v16+

MongoDB v5+

npm v8+
